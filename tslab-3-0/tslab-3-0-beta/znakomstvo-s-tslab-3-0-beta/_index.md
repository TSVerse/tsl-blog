### Введение

Мы рады сообщить о старте открытого бета-тестирования новой версии программы TSLab 3.0! Эта версия предназначена для ознакомления с новыми возможностями и сбора обратной связи.

Скачать инсталлятор можно по ссылке: [TSLab 3.0 Beta](https://files.tslab.pro/beta/TSLab30BetaSetup.exe)

### Важные предупреждения

#### Ограничения бета-версии

-  В программе могут содержаться ошибки, не обнаруженные на этапе внутреннего тестирования

-  **Не рекомендуется** торговать крупными суммами через TSLab 3.0 на данном этапе

-  Не запускайте один и тот же агент, настроенный на одинаковый инструмент в разных версиях программы.

-  Используйте бета-версию для тестирования и освоения новых возможностей

#### Совместимость с TSLab 2.2

TSLab 3.0 можно установить на один компьютер с версией 2.2 -- установка выполняется в разные директории и файлы программ не пересекаются. Однако одновременно может работать только один экземпляр программы: либо TSLab 2.2, либо TSLab 3.0.

❗**Важно**: перед первым запуском TSLab 3.0 закройте все окна визуального редактора в версии 2.2, затем полностью завершите работу TSLab 2.2.

#### Рекомендации по настройке

-  Создайте отдельный файл конфигурации окон для TSLab 3.0

-  При работе с поставщиком **Т-Инвестиции** (если он был создан в TSLab 2.2) повторно введите API-ключ в настройках поставщика
